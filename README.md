# SimpleMon Agent

SimpleMon Agent collects Linux host metrics and sends them to a compatible
SimpleMon backend. Register a server in your SimpleMon panel to get its
installation command and credentials.

## Install on Linux

Use the installation command generated by the panel for the registered server.
It installs the agent as a systemd service. Current binary builds target Linux
amd64, arm64, 386 and ARM. The collectors rely on Linux `/proc` and `/sys`.
In a container, metric visibility depends on the container's namespaces,
mounts and permissions.

## Build and run from source

Go 1.22 or newer is required.

```sh
git clone https://github.com/cookiebinary1/simplemon-agent.git
cd simplemon-agent
go test ./...
go build -o simplemon-agent ./cmd/simplemon-agent
(umask 077 && cp simplemon.conf.example simplemon.conf)
chmod 600 simplemon.conf
```

Edit `simplemon.conf` using the host and credentials from the panel. Then run:

```sh
./simplemon-agent -config ./simplemon.conf
```

For a manual systemd install, place the completed configuration at
`/etc/simplemon.conf` and run
`sudo bash installers/linux/install.sh ./simplemon-agent`. The installer makes
the config readable by the service account. It runs the agent as `nobody`
with Linux capabilities for reading metrics from other processes.

## Configuration

With no `-config` flag, the agent tries `./simplemon.conf` and then
`/etc/simplemon.conf`. Keep the API key and server token in the config file
with restricted permissions.

| Field | Purpose |
| --- | --- |
| `serviceHost` | Backend hostname with an optional port, without the URL scheme |
| `secure` | Set to `true` for HTTPS and WSS |
| `apiKey`, `serverToken` | Credentials issued by the panel |
| `metricInterval` | Collection interval in milliseconds (default 1000) |
| `storeInterval` | Interval for averaged samples in milliseconds (default 10000) |
| `batchInterval` | Batch upload interval in milliseconds (default 10000) |
| `verbose` | Enable verbose logging (default false) |
| `healthPort` | Disabled by default. A nonzero port exposes unauthenticated `/health` and `/ready` endpoints on all interfaces. Restrict network access if enabled. |

## Data sent to SimpleMon

The agent sends CPU, memory, filesystem usage, disk I/O, network and system
metrics. Payloads can include process names and resource usage, mount paths,
network interface names, host IP addresses, hostname, OS and kernel details, and hardware
information. Process visibility depends on the agent's permissions.

The agent uploads gzip-compressed batches to `/api/v1/metrics/batch` and connects
to `/incoming` over WebSocket. The backend can start and stop live streaming
over that connection. Live streaming expires after 30 seconds without a
keepalive.

## Updates and contributions

Run `simplemon-agent -version` to check an installed build. GitHub
[tags](https://github.com/cookiebinary1/simplemon-agent/tags) identify published
source snapshots. The SimpleMon panel serves the managed binaries and
`SHA256SUMS` alongside the license files. The Linux installer can enable daily updates via a systemd timer
when supplied with `SIMPLEMON_BIN_BASE_URL`.

Use [GitHub Issues](https://github.com/cookiebinary1/simplemon-agent/issues) for
bugs and suggestions. Include the agent version, Linux distribution and
architecture. Remove credentials and private host details from logs.
